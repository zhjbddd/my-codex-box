下载 Book Taker 客户端

独立桌面客户端，选择本地 PDF / EPUB / TXT / Markdown 即可拆书。 不需要先安装 Python。API 密钥只保留在本次会话内存中。

Windows book-taker-client-windows-x64.exe macOS book-taker-client-macos-arm64 Linux book-taker-client-linux-x64

若最新 Release 尚未发布客户端构建，请打开 GitHub Releases 查看可用文件，或从源码启动：

python -m pip install -e . && book-taker-client
