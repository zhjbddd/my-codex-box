# Changelog

All notable changes to this project will be documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use semantic versioning.

## [Unreleased]

### Added

- Desktop client for Windows, macOS, and Linux, with GitHub Release download links.
- Shared Book Taker pipeline used by both the CLI and the desktop client.
- Session-only API key entry in the client; keys are not written to disk.

## [0.1.0] - 2026-08-12

### Added

- Installable Python CLI for text PDF, EPUB, TXT, and Markdown books.
- Chapter discovery from bookmarks, mapped contents, headings, and explicit fallback modes.
- Deterministic source verification for quotations and RIA source passages.
- Input, archive, XML, output-directory, response-size, HTTPS, and prompt-injection boundaries.
- Self-contained Agent Skill and validated Codex Plugin package.
- Cross-platform CI, synthetic tests, security policy, and contribution templates.
